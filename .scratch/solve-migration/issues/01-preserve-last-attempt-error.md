# 01: 重试无候选时保留最近一次真实失败

Status: completed (2026-10-15)

**Spec:** ../spec.md

**What to build:** 在既有 Relay 和任务提交控制器中，仅当选路没有新故障而候选为空时保留本次最近一次真实尝试的失败；任务错误完整保真，本地错误来源不变。

**Blocked by:** None.

- [x] 普通 Relay 的上游 429/503 不再被无候选错误覆盖，保留既有脱敏与展示语义。
- [x] 最近一次失败优先；没有历史尝试时维持原无渠道返回。
- [x] 本地可重试渠道容量失败保留本地来源，新选路/并发系统故障优先。
- [x] 任务保留原错误的状态码、业务码、消息、数据、来源及禁止重试语义。
- [x] 新提交与成功后清理历史，正常换渠成功、已写响应和已接受任务行为不变。
- [x] 在现有控制器测试入口完成 red → green 回归，完整后端测试与双轴代码审查完成。
