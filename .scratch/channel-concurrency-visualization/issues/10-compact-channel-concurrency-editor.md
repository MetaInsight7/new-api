# 10: 紧凑渠道并发状态与弹层编辑

**What to build:** 将渠道列表和负载监控页的渠道并发状态统一为单行紧凑控件：静态状态显示 `active/max`、正数排队和冷却，可写管理员点击分母或“不限并发”后在弹层中使用数字步进器调整上限；连续操作 800ms 合并自动保存，失败回滚，降低上限时允许并明确显示超限。

**Blocked by:** 06

**Status:** implemented

- [x] 普通渠道列表的并发列紧跟权重，状态、排队和冷却保持同一行，不再常驻显示第二个最大并发数字控件。
- [x] 只读管理员看到紧凑状态但没有编辑触发器；拥有 `ChannelWrite` 的管理员可点击分母或“不限并发”打开可访问的编辑弹层。
- [x] 弹层复用现有 `NumericSpinnerInput`，接受非负整数，`0` 表示不限并发；连续变化等待 800ms 合并保存，关闭、失焦或卸载时提交待保存值。
- [x] 保存期间提供明确状态，成功后刷新渠道与快照查询；失败恢复服务端原值、显示既有错误反馈并允许重试。
- [x] 基础状态区分不限并发、空闲、运行中、满载和超限；等待与冷却为可共存徽标，`active > max` 显示红色超限而不阻止平滑降限。
- [x] 无限并发渠道不伪造 `0/0`，标签汇总行继续不可编辑，普通渠道列表移动布局继续隐藏该能力。
- [x] 组件测试覆盖权限、弹层键盘交互、自动保存合并、关闭提交、清零、失败回滚、超限、多状态共存、列顺序和不换行。
