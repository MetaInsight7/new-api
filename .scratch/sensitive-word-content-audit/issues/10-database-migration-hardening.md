# 10: 交付数据库迁移与跨方言加固

**What to build:** 新旧数据库和滚动升级环境可以安全启用敏感词风控，PostgreSQL、MySQL 与 SQLite 保持相同数据语义。

**Blocked by:** 05/交付自动封禁与分离解封；08/交付审计证据到期清理；09/交付多实例策略同步与故障语义

**Status:** ready-for-agent

- [ ] 新库、旧敏感词配置和重复执行迁移都产生同一规范化结构与迁移标记。
- [ ] MySQL 使用可容纳 512 KiB 证据与集合字段的类型，不依赖静默截断。
- [ ] PostgreSQL/MySQL 多连接并发验证用户锁、请求唯一约束、计数和封禁事务。
- [ ] SQLite 快速回归与真实 PostgreSQL/MySQL 行为一致。
- [ ] Slave／非迁移节点不会读取或执行部分迁移规则。
- [ ] 大证据、截断标记、分批清理和恢复操作在各方言一致。
