# 09: 交付多实例策略同步与故障语义

**What to build:** 多实例部署中的每个节点快速取得一致策略，并在 Redis、数据库或审计写入发生短暂故障时遵守明确的放行与阻断边界。

**Blocked by:** 03/交付阻断、持久计数与请求幂等；06/交付分组规则与自动分组匹配；07/交付结构化审计证据与读取权限

**Status:** completed

- [x] 每个节点使用不可变本机策略快照处理请求，不在每次请求读取数据库策略版本。
- [x] 策略或规则提交后广播 Redis 刷新通知，遗漏通知由周期代次检查收敛。
- [x] 刷新失败继续使用最后一个有效快照并产生运维告警。
- [x] 迁移完成但从未加载有效快照的节点失败关闭；迁移标记尚不存在时新运行时保持未启用。
- [x] `observe` 审计持久化失败时放行并告警。
- [x] `block` 审计持久化失败时仍不允许请求进入上游，且不伪造未提交的计数或封禁。
- [x] 缓存发布、会话撤销或 Token 缓存失效的单项失败不会阻止其他失效步骤。
