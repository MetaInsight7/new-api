# 06: 交付分组规则与自动分组匹配

**What to build:** 管理员可以把敏感词规则限定到真实定价分组，并让普通分组与自动候选分组使用确定且高效的匹配语义。

**Blocked by:** 02/交付全局观察规则完整链路

**Status:** completed

- [x] 规则可以选择全局或一个及以上真实定价分组，不能绑定虚构分组或 `auto` 本身。
- [x] 全局与命中候选分组的规则在一次字段扫描中共同评估。
- [x] 自动分组按既有候选顺序决策，不因敏感词检查改变路由顺序。
- [x] 同时命中 `block` 与 `observe` 时由 `block` 决定处置。
- [x] 管理界面支持分组选择、模式切换和现有规则编辑。
- [x] 分组规则不授予模型权限，也不改变分组倍率或计费。
