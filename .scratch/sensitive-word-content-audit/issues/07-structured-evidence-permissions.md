# 07: 交付结构化审计证据与读取权限

**What to build:** 授权审计人员可以查看有界、结构化且足以复核命中的上下文，同时普通日志和无权限管理员无法取得敏感证据。

**Blocked by:** 04/交付白名单与角色处置

**Status:** completed

- [x] 审计证据保存 system/developer、当前项和此前三轮审计轮次，Tool 链归属发起它的用户轮次。
- [x] 命中字段优先保留，序列化总量不超过 512 KiB，并明确记录截断状态。
- [x] 图片、音频、文件、Base64 和二进制内容不进入审计证据。
- [x] 风控管理权限与审计读取权限相互独立。
- [x] 非 Root 即使拥有审计读取权限，也不能读取 Root 的完整审计证据。
- [x] 普通日志不泄露命中词、规则详情、Prompt 哈希、审计 ID 或上下文。
- [x] 授权后台审计详情正确展示结构化上下文和处置结果。
