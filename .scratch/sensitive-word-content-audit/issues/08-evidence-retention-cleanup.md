# 08: 交付审计证据到期清理

**What to build:** 系统按配置期限分批清理敏感内容型证据，同时永久保留可解释的审计事实和账号处置历史。

**Blocked by:** 07/交付结构化审计证据与读取权限

**Status:** ready-for-agent

- [ ] 审计证据默认保留 180 天，期限可沿用策略配置。
- [ ] 到期清空结构化上下文、脱敏预览和命中片段，但保留审计事实。
- [ ] 清理按有界批次执行，单批失败可重试且不会重复破坏已清理记录。
- [ ] 多节点只由获得现有系统任务所有权的执行者处理同一轮清理。
- [ ] 系统任务结果报告本轮清理数量和失败状态。
- [ ] 敏感词违规次数不因证据到期发生变化。
