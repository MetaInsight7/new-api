# 05: 交付自动封禁与分离解封

**What to build:** 运营可以按需开启阈值自动封禁，并通过与普通账号启用分离的敏感词解封流程安全恢复用户。

**Blocked by:** 04/交付白名单与角色处置

**Status:** ready-for-agent

- [ ] 自动封禁拥有独立开关且默认关闭，单一全局阈值可配置。
- [ ] 开启自动封禁不会清除或忽略已有累计次数。
- [ ] 普通用户和非 Root 管理员达到阈值后只禁用账号并失效现有认证状态。
- [ ] Root 永不自动封禁，白名单永不自动封禁。
- [ ] 封禁不修改余额、额度、订阅、历史账务或 API Key 持久状态。
- [ ] 普通启用账号保留次数；专用敏感词解封启用账号并清零；单独清零仍可独立执行。
- [ ] 恢复后原有有效 Key 随账号恢复，疑似泄露 Key 继续由现有 Key 管理处理。
