# 03: 交付阻断、持久计数与请求幂等

**What to build:** 普通用户命中阻断规则时在渠道选择和计费之前被拒绝、审计并准确累计一次，重复交付同一请求不会重复计数。

**Blocked by:** 02/交付全局观察规则完整链路

**Status:** ready-for-agent

- [ ] `block` 命中返回协议兼容的 HTTP 400 和稳定错误码 `sensitive_words_detected`。
- [ ] 阻断请求不进入渠道选择、额度预扣、插件执行或上游请求，并禁止普通上游重试。
- [ ] 可解析请求即使随后无渠道、模型不可用或额度不足也先执行风控；格式错误请求不计数。
- [ ] 每个阻断请求只累计一次，重复命中词不放大次数。
- [ ] 用户与请求身份具有真实数据库唯一约束，并发重复交付保持一个审计事实和一次计数。
- [ ] 计数不随时间或审计证据清理自然衰减。
