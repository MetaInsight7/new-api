# 02: 交付全局观察规则完整链路

**What to build:** 管理员可以迁移旧配置、创建和管理全局敏感词规则，并以观察模式在真实请求上形成审计事实而不阻断用户。

**Blocked by:** 01/建立结构化敏感文本提取接缝

**Status:** completed

- [x] 新策略、规则、词条和审计事实结构可幂等迁移，旧配置只作为一次性迁移输入。
- [x] 管理员可以通过当前后台查看和维护全局规则，新增规则默认 `observe`。
- [x] 观察规则通过真实路由检查结构化文本，请求继续进入既有 Relay 流程。
- [x] 一次匹配形成一个审计事实，不增加敏感词违规次数。
- [x] `off` 规则不参与匹配，规则和策略更新推进持久代次。
- [x] 管理界面遵守当前权限、组件和本地化约定。
