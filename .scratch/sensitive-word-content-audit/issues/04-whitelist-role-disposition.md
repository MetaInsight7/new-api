# 04: 交付白名单与角色处置

**What to build:** Root、非 Root 管理员、普通用户和显式白名单用户按照确定的身份策略获得一致、可见且可管理的敏感词处置。

**Blocked by:** 03/交付阻断、持久计数与请求幂等

**Status:** completed

- [x] Root 命中阻断规则时被阻断、审计并累计，但不会因角色自动获得白名单。
- [x] 非 Root 管理员与普通用户使用相同的阻断和计数逻辑。
- [x] 显式白名单用户命中后放行、审计、不累计且不自动封禁。
- [x] 添加或移除白名单不修改已有敏感词违规次数。
- [x] 风控管理员可以查看和修改用户白名单与违规次数，操作受独立风控管理权限保护。
- [x] 相同请求身份在白名单和非白名单路径上保持幂等。
