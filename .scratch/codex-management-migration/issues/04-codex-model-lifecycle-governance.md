# 04: Codex Model Governance 模型生命周期治理

**What to build:** 管理员在独立治理页查看 Codex 不支持模型的证据与受影响渠道，配置主动探测和公告判定，并审核禁用、恢复、忽略和确认移除，保留备注与告警冷却。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 来源最终治理模型、错误规则、请求证据、主动探测、公告／AI 发现、设置、通知与前端审核闭环完整对齐。
- [ ] 默认关闭治理和主动探测，不自动抓外部公告或调用 AI；普通临时错误不触发明确不支持判定。
- [ ] 仅抑制对应 Codex 渠道模型能力；人工恢复、渠道编辑、能力重建和通用健康探测不会意外解除未恢复的治理抑制。
- [ ] 官方来源访问遵循 Base SSRF／超时／体积保护；公告／AI 推断需审核，不自动删除模型。
- [ ] 持久化探测与告警状态、审核范围、缓存通知、多节点执行和管理员权限完整。
- [ ] 新建／升级数据库和重复迁移在真实 SQLite/MySQL/PostgreSQL 验证；规则／审核／探测回归、前端类型检查／lint 与 Playwright 完整。
