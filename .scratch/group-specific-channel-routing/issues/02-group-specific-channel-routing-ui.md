# 02: 增加渠道分组优先级/权重可视化配置

**What to build:** 在 Base 原生渠道编辑和列表界面提供分组策略覆盖的可视化管理，使管理员可以添加、修改、删除覆盖并识别已配置覆盖的渠道，不需要手写 JSON。

**Blocked by:** 01: 支持按用户分组覆盖渠道优先级和权重

**Status:** implemented

- [x] 渠道编辑界面支持选择用户分组并设置优先级、权重或其中一个字段。
- [x] 删除覆盖后恢复全局优先级/权重。
- [x] 编辑已有渠道和新建渠道均保留正确的覆盖配置。
- [x] 全局值明确说明其回退值和主动探测排序作用。
- [x] 渠道列表显示已配置覆盖的分组提示。
- [x] 不增加第一版批量分组覆盖编辑。
- [x] 完成受影响 Vitest、TypeScript、lint、格式检查和 Playwright 验证。
