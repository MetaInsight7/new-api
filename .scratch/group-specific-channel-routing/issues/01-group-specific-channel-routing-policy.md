# 01: 支持按用户分组覆盖渠道优先级和权重

**What to build:** 为渠道增加可选的用户分组策略覆盖，使真实请求根据已解析的用户分组使用有效优先级和权重，同时保持旧渠道、`auto` 分组、重试、并发、健康过滤和主动探测行为兼容。

**Blocked by:** None (can start immediately)

**Status:** implemented

- [x] 保存和读取可选的分组优先级/权重覆盖，旧渠道无配置时行为不变。
- [x] 普通分组请求使用对应覆盖，未配置字段逐项继承全局值。
- [x] `auto` 分组先按既有顺序确定实际分组，再使用实际分组覆盖。
- [x] 优先级降级、同级权重随机、健康过滤、并发控制和请求策略继续生效。
- [x] 主动模型探测使用全局优先级/权重，不产生分组维度状态。
- [x] 覆盖非法、旧数据、负优先级和负权重边界有回归测试。
