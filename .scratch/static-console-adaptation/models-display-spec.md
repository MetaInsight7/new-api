# 官网模型报价展示精简

状态：已完成实施、验证及 Static 独立提交 `b4e8d47`，实际结果见 [展示验收记录](models-display-verification.md)。本文覆盖先前 Spec 中主表阶梯标记、缓存单独展开和原始表达式展示的政策；计算、分组权限、当前时段选择及来源规则不变。

后续入口与图标修订见 [官网模型价目表入口与图标修订](models-controls-spec.md)：四位价格、最低文案、标签列展开入口及供应商图标代码已调整，当前仍等待本轮浏览器验收与独立提交；本 Spec 的历史通过结果不替代新改动验收。

## 需求与设计

- 将用户所写“按词”按现有页面“按次”理解，计费列和筛选只保留“按量 / 按次”，不显示“动态”、混合或来源数量作为计费类别。
- Token、按秒等使用量计费归为按量；按次、按张等固定项目归为按次。混合计费包含使用量项目时归为按量，实际金额单位不改变。
- 主表及移动摘要只展示价格和单位；移除“首档参考价”、内部档名和默认条件。分时模型仍保留简短分时提示，避免让当前价格看起来永久有效。
- 不在页面渲染原始计费表达式，包括隐藏的展开内容。源码许可证与下载入口保留，不改变公开 API。
- 计费明细只由实际多档价格或时间条件触发，不能由表达式模式、缓存 5m/1h、模态项目、多个来源、未知配置本身触发。
- 多分组“分组价格”展开与“计费明细”区分；缓存单价本身不算分时计费。普通单档模型不显示明细按钮。
- 明细改成价格对照表：行表示适用范围或时段，列表示输入、输出及实际配置的缓存等价格；分时表标识当前时段，不复制一套当前价格卡片。
- 移动明细采用每档独立的条件与价格列表，避免宽表撑开页面。内部 `standard/base` 档名不作为普通用户理解价格的必要信息。
- 条件展示复用 Base AST，使用中文、千分位和时间说明，不另写计算解析器，也不执行表达式。无法准确解释的条件不猜具体区间。
- 多来源仍独立显示真实报价与未配置状态，不为了取消明细入口而丢失来源价格；未知报价不回退旧价、不伪造零。

## 验证与范围

对展示分类、明细触发、条件格式运行 Node 回归；Playwright 验证桌面/移动、普通缓存无入口、多档与分时展开、无原始表达式或主表冗余文案、筛选一致、来源报价、当前时段刷新、公开真实 API 和控制台错误。

仅修改 Static `/models` 展示及相关测试/文档，不改 Go 后端、计费结算、管理员配置或排行榜；独立提交，不推送或重启 3000/5173。
