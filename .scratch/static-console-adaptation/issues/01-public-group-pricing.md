# 01: 官网公开模型有效分组报价

**What to build:** 官网访客在传统定价模型上选择分组或“全部 · 最优”时，看到已经正确应用模型专属倍率的参考价，只能展开该模型公开可用的分组。原生公开定价接口提供可复用、向后兼容的倍率数据，在线与匿名快照保持同一口径。

**Blocked by:** None (can start immediately).

**Status:** complete

- [x] 原生公开定价接口增加受可见模型及分组范围约束的专属倍率，不导出完整管理员配置。
- [x] 复用现有模型匹配，专属倍率覆盖普通倍率而非相乘；显式零正确保留。
- [x] 官网分组折算、模型行倍率和最优选择一致；裁剪隐藏组并正确展开 all。
- [x] 传统 Token 与按次定价单位保持原语义，小额非零不因中间舍入变成免费。
- [x] 接口、Node 和桌面/移动 Playwright 验证通过，后端与官网修改分别提交。

后端提交：`7857d181a`；官网提交：`1c6067a`。验收包括公开 HTTP 契约、controller 与倍率包测试、后端构建、Node 报价/快照测试及桌面/移动 Playwright。实际命令及部署边界见 [验收记录](../verification.md)。
