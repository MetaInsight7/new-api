# 02: 官网表达式报价明细与当前时段参考价

**What to build:** 官网访客看到表达式模型的首档参考价，可展开缓存、完整阶梯及所有计费来源。分时基价随当前时段更新，分时附加倍率另列；任务和固定价按真实单位显示，无法可靠解释时有明确状态而非伪造零价。

**Blocked by:** 01 — 官网公开模型有效分组报价。

**Status:** complete

- [x] 复用 Base 纯表达式解析能力，提供可复现、记录来源版本的独立浏览器产物，不引入 Console 运行时。
- [x] 桌面/移动主摘要保留首档输入输出；单分组模型也能展开缓存、模态及完整阶梯。
- [x] 可识别的 Token 分时基价显示当前时段首档价，分钟边界和页面可见性恢复时更新；完整时区规则仍可展开。
- [x] 分时/请求附加倍率独立呈现，未知时段或不支持语法不猜价格。
- [x] 固定、混合、任务及多 provider 元信息正确显示单位、条件和配置状态，不拼合虚假最低账单。
- [x] 在线与匿名快照使用同一解释层；Node 测试和桌面/移动 Playwright 验证通过后独立提交。

官网提交：`ac389b3`。公开源码包包含全部纯解析器及类型定义、原许可证和独立构建脚本，解包构建与发布产物逐字节一致。验收覆盖首档适用条件、缓存与音频显式零、分时边界、可见性恢复、单分组展开、实际单位、独立 provider、未知格式、离线快照及桌面/移动筛选分页；见 [验收记录](../verification.md)。
