# 官网模型价目表入口与图标修订

日期：2026-10-09。状态：代码已实施，回归及语法检查通过，等待浏览器验收；尚未提交。

本修订补充 [展示精简 Spec](models-display-spec.md)，不改变计费计算、公开接口、分组权限或已完成的主表精简政策。

## 用户要求与实施

1. 将“最优组”改成“最低”，分组选择器及展开比价使用一致文案。
2. 金额统一保留四位小数，包含主表、移动摘要、来源报价和展开价格。API 返回数值；小数位由前端控制。计算与选组不使用格式化字符串，不恢复旧 Static 先三位再四位的二次舍入。
3. 黄色按钮只表示多分组数量，不混入“明细”。单分组不为计费规则额外生成黄色按钮。在模型标签列放置可展开的“分段计费 / 分时计费”按钮；移动端放在模型标签区域。时段变化不误标为长度分段，二者共存时展示两个入口，展开状态同步。
4. 图标优先消费供应商 `icon` 配置，复用 Console 所用版本的官方 Lobe 图形，而不是忽略配置后仅猜四个品牌。公开 Static 使用本地 SVG，不加载 React 或第三方 CDN；保留已有未配置品牌推断和未知配置的文字回退。

## 图标范围与复用

Console 的供应商图标调用 `getLobeIcon(model.vendor?.icon, 32)`。Static 复用同一依赖中的 Mono/Color 图形：321 个品牌、537 个 SVG 标志；其他变体降级为普通图形，不迁移 Avatar 容器或文字组合 UI。当前 MiniMax 彩色和 OpenAI 单色配置有针对性回归。

生成脚本复用已安装的 `@lobehub/icons`，导出独立 SVG、轻量索引、来源版本与 SHA-256，并保留原 MIT 许可证。每个图形内的 ID 和渐变引用进行命名空间隔离，避免同页标志相互污染。构建只导出图形，不打包 Console；使用 Bun `--smol` 和低调度优先级。

## 验收边界

回归覆盖固定四位显示但原始数值不变、图标配置优先级、MiniMax 图形、未知和恶意配置、图形索引与完整性、唯一 ID 与完整渐变引用、纯分时与分时加阶梯的区分。

Playwright 需覆盖桌面标签列、移动标签区域、多组黄色按钮、单组无黄色按钮、两个入口的展开同步、四位价格、SVG 实际绘制、已有筛选/分页/时段刷新/真实公开 API。不得使用之前截图或之前任务的通过结果代替本次验收。

所有代码改动在 Static `master`；`new-api/tokendazi_op` 只增加本轮规划记录。前后端原有进程不重启，不修改其他页面和后端，不 push。只有浏览器验收完成后才独立提交功能。
