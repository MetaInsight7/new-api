# 模型专属分组倍率可视化配置

## 范围与来源

在 `tokendazi_op` 完成已有 `GroupModelRatio` 的可视化配置。参考二开最新版 `solve/main@762ce21c4` 的 `group-model-ratio-editor.tsx` 最终实现，不回退 Base 分组语义，不重写计费或 Available Models 后端。任务保存在本地仓库，不代表已创建 GitHub Issue 或已 push。

## 交付行为

- 在现有计费设置的分组定价区域展示模型专属倍率编辑器，按分组折叠，支持添加模型、修改计费模型键和倍率、删除覆盖以及为已有配置中的其他分组编辑覆盖。
- 可视化与 JSON 使用同一个 `GroupModelRatio` 表单字段、保存按钮和现有 options API，切换视图不丢失合法修改，不覆盖其他分组或模型配置。
- 沿用后端计费模型键规范化：Gemini 2.5 thinking budget 与 GPT gizmo 名称使用后端支持的归一化键；不扩展为任意前缀／通配匹配。
- 接受明确输入的零倍率；空值、负数、非有限数字不能被静默转成免费倍率，非法 JSON／数据结构不能被编辑器重写成空配置。重名模型键不能覆盖已有值。
- 继续保留未知分组与未在渠道中出现的模型键；倍率配置不新建用户分组、不授予模型权限。
- 成功保存后失效当前浏览器的模型访问缓存。Available Models 在对应可用分组显示配置模型的专属倍率；无覆盖的模型不出现专属倍率标记，删除覆盖恢复继承。当前卡片右侧为基础价格，保留既有展示规则，不在本功能中静默改为折后价；实际计费使用专属倍率覆盖默认倍率，不相乘。
- 不增加数据库字段、接口、计费规则、PLG 分组或倍率相乘语义。

## 适配理由

二开编辑器将空数字输入转换为零，非法配置解析失败后退为空对象，重名模型键静默拒绝；直接复制会产生误配置。保留其折叠分组及增删编辑流程，但增加可见校验和保存保护。复用 Base 的 Card、Collapsible、Input、Button、错误／空状态与 JSON 解析能力。现有 DraftNumberInput 也将空值转为零，不适合这个具有“零表示免费”含义的配置，因此使用现有 Input 并显式验证。

## 验证

- 定向行为测试覆盖可视化创建／修改／删除、JSON 双向同步、未知配置保留、零倍率、空／负倍率、重名拒绝、模型键规范化和错误状态。
- 保存成功后的模型访问缓存失效必须有回归测试，失败保存不得伪造刷新成功。
- 运行受影响前端测试、类型、lint、格式检查和资源受限生产构建；前端任务串行，限制内存和 CPU。
- Playwright 使用真实管理界面保存临时覆盖，在 Available Models 验证专属倍率、基础价格不受倍率设置改变、刷新后持久化和删除后的继承。测试结束恢复原配置，不请求真实模型。
- 运行已有模型倍率及模型访问投影 Go 回归，确保现有计费、权限与模型范围不变。

## 不做

- 不实现 R2 下载限流、域名代理或其他 Codex 功能。
- 不实现倍率批量导入系统、创建模型元数据、自动建立用户分组或独立模型配置路由。
